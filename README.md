# TCC - Geração de Casos de Teste com IA Generativa

Projeto desenvolvido como parte do Trabalho de Conclusão de Curso em Sistemas de Informação.

O objetivo é desenvolver e avaliar uma aplicação web para geração de casos de teste a partir de casos de uso escritos em linguagem natural.
