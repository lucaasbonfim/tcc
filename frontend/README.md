# Frontend

Interface do experimento de geracao de casos de teste com IA generativa.

## Tecnologias

- React
- Vite
- JavaScript
- React Router DOM
- Axios
- Tailwind CSS

## Instalacao

```bash
npm install
```

## Configuracao

Crie um arquivo `.env` com base em `.env.example`:

```env
VITE_API_URL=http://localhost:3000/api
```

## Desenvolvimento

```bash
npm run dev
```
